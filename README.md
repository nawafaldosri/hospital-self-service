# Hospital Self-Service System

نظام خدمة ذاتية تجريبي للمستشفى.

## المميزات

- تسجيل المريض برقم الهوية أو الإقامة
- إنشاء ملف جديد للمريض
- اختيار التخصص والطبيب
- عرض عدد المرضى في الانتظار
- تسجيل الدفع بشكل تجريبي
- إصدار إيصال
- ربط البيانات مع MySQL

## التقنيات المستخدمة

- PHP
- MySQL
- XAMPP
- HTML
- CSS
- JavaScript

## ملاحظة

هذا المشروع نموذج تجريبي فقط، وليس نظامًا طبيًا أو ماليًا جاهزًا للاستخدام الحقيقي.
